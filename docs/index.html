# Base URL

https://gzw-data.vercel.app

All endpoints are prefixed with /api/. Every response includes CORS headers.

# Authentication

No authentication required. The API is fully open and free to use.

# Rate Limiting

100 requests per minute per IP address. Rate limit info is returned in response headers:

X-RateLimit-Limit: 100
X-RateLimit-Remaining: 87
X-RateLimit-Reset: 1721234567

If you exceed the limit, the API returns HTTP 429.

# Response Format

All endpoints return JSON with this structure:

{
  "data": [ ... ],
  "count": 44,
  "source": "GZW Data API",
  "timestamp": "2026-07-28T12:00:00.000Z"
}

# Endpoints

Every data file is automatically available as /api/<name>. New categories appear automatically.

# Query Parameters

Field filters

Filter by any string field. Case-insensitive.

curl "/api/vests?nij=III&material=Ceramic"
curl "/api/ammo?caliber=5.56x45mm%20NATO"
curl "/api/keys?type=Keycard"

Free text search

Search across all fields with ?search=.

curl "/api/weapons?search=AK"
curl "/api/tasks?search=artifact"

Sorting

Sort by any field with ?sort=field:asc|desc.

curl "/api/weapons?sort=name:asc"

Pagination

Use ?page= and ?per_page= (default: 50, max: 500). Use ?all=true to disable.

curl "/api/weapons?page=2&per_page=10"

Limit results

Cap results with ?limit=.

curl "/api/tasks?limit=5"
