GZW Data API

Privacy Policy

Last updated: November 2026

GZW Data API is a free, fan-made Gray Zone Warfare data project. This policy explains what information may be processed when you use the website or API.

Who is responsible

GZW Data is run by an individual maintainer (GitHub: ZoniBoy00), who is the controller of any personal data described in this policy. Contact details are listed at the bottom of this page.

Information we collect

GZW Data does not ask for accounts, names, payment details, or other personal information. The website does not use advertising trackers or tracking cookies, so no cookie consent banner is shown. It uses Vercel Web Analytics, a privacy-friendly service that counts page views, referring sites, and country, browser and device type in aggregate. It sets no cookies, does not track you across websites, and does not store your IP address. See Vercel Web Analytics privacy.

The API uses the requesting IP address temporarily, in server memory only, for rate limiting. This helps enforce the limit of 100 requests per minute per IP address. The address is not written to a database and we do not use it to build user profiles.

Emails and feedback

The feedback and support links on this site open your own email client (mailto:). We do not receive anything until you choose to send a message. If you email us, we process your email address and the contents of your message only to answer you and to improve the project, and we delete it when it is no longer needed. Public GitHub issues are governed by GitHub's privacy policy.

Hosting and server logs

The site and API are hosted on Vercel. Vercel may process standard technical information, such as IP addresses, request timestamps, user-agent data, and request paths, in its infrastructure and security logs. These logs are controlled by the hosting provider and may be retained according to Vercel's policies. See Vercel's Privacy Policy for details.

Local storage and cookies

GZW Data does not set cookies and does not store personal information in your browser. The website keeps one small, non-personal cache in your browser's sessionStorage: the latest published version numbers of the JavaScript and Python client packages, for up to one hour. It is deleted when you close the tab and is strictly technical, so no consent is required. Your browser or the hosting infrastructure may also handle technically necessary data as part of delivering a web page or API response.

Package registry requests

Pages that show client package versions make a request from your browser to npm (registry.npmjs.org) and PyPI (pypi.org). Those services receive your IP address and browser details as with any web request and handle them under their own privacy policies. If the requests fail, the page shows a built-in fallback version and works normally.

Your rights

If you are in the EU/EEA, you have the right to ask what personal data we hold about you, to request correction or deletion, and to complain to your local data protection authority (in Finland, the Office of the Data Protection Ombudsman). Because we keep no accounts or databases, the only data we may hold is the content of emails you have sent us. Contact us to make a request.

Data source and external links

The game data is sourced from the GZW Fandom Wiki. Links to external websites are governed by those websites' own privacy policies. GZW Data is not responsible for the privacy practices of third parties.

Changes to this policy

This policy may be updated when the site, API, hosting provider, or data practices change. The latest version will always be published on this page.

Contact

Privacy requests and questions: support@gzw-data.dev. They can also be raised through the GZW Data GitHub repository.
