Quick start

All routes are read-only and return JSON. Use /api/v1 for new integrations.

1. List a dataset#

curl "https://gzw-data.dev/api/v1/weapons?per_page=5"
const res = await fetch("https://gzw-data.dev/api/v1/weapons?per_page=5");
const { data } = await res.json();
import requests

data = requests.get("https://gzw-data.dev/api/v1/weapons?per_page=5").json()["data"]

2. Fetch one record#

Records are addressed by canonical ID. Reviewed legacy IDs resolve to the same record.

curl "https://gzw-data.dev/api/v1/weapons/ak-12"
const res = await fetch("https://gzw-data.dev/api/v1/weapons/ak-12");
const { data } = await res.json();
import requests

data = requests.get("https://gzw-data.dev/api/v1/weapons/ak-12").json()["data"]

3. Read the response#

Every successful response carries data, source, timestamp and dataVersion. See Response format.

example response
{
  "data": { "name": "AK-12", "id": "ak-12", "type": "Assault Rifle", "caliber": "5.45x39mm" },
  "source": "GZW Data API",
  "timestamp": "2026-11-03T10:04:10.944Z",
  "dataVersion": "2026-11-02T16:13:19.465474Z"
}

Next steps#

  • Narrow results with filters, search and pagination.
  • Skip hand-written fetch code with a client library.
  • Copy more recipes from Examples, or build a request in the Playground.
  • Check the rate limit and caching rules before shipping.
Tip

The dataset list grows automatically as the scraper discovers new categories. Discover datasets at runtime from GET /api/v1 instead of hard-coding them.
