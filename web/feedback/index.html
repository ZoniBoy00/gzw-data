Send feedback to the right place

GZW Data is community-maintained. A short, reproducible report helps us fix the right thing faster.

01 · Data quality

Missing or incorrect data

Use this for a missing weapon, mission, item, price, image or incorrect value.

Open a data issue ↗

02 · API support

API question

Ask about endpoints, datasets, pagination, responses or SDK usage.

Email API support ↗

03 · Product feedback

Feature request

Suggest a useful API, documentation improvement or developer workflow.

Suggest a feature ↗

04 · Security

Private vulnerability report

Do not open a public issue for a security problem. Send only security reports here.

Contact security ↗

Good report checklist

Include these details

  • page or API endpoint
  • dataset and record ID, if relevant
  • what you expected and what happened
  • a small reproducible request or example

Never include passwords, API tokens or private personal data.
