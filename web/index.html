Make your first request

Copy a command. No signup, no key.

  1. 1

    Call the API

    Every dataset is a JSON endpoint under one base URL.

    curl https://gzw-data.dev/api/v1/weapons?per_page=3
  2. 2

    Search & filter

    Search one dataset, or all of them at once.

    curl https://gzw-data.dev/api/v1/search?q=AK
  3. 3

    Use the SDK

    Typed, zero-dependency client for Node and browsers.

    npm install @zoniboy/gzw-data-client

What you can rely on

One predictable API, updated on a schedule, with the source of every dataset documented.

◈

Auto-discovered datasets

Every JSON file in the data repository becomes an endpoint. New wiki categories appear without route code.

{ }

Stable response contract

One envelope for every dataset, stable error codes, pagination, filters and sorting. Breaking changes need a new API line.

↻

Reviewed weekly updates

A scraper refreshes the data every week and opens a pull request, so changes are reviewed and a drop-guard blocks accidental data loss.

§

Transparent provenance

Data comes from the community wiki under CC BY-SA. Licensing, sources and revision hints are documented openly.
