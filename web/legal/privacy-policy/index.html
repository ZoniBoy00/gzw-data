GZW Data API

Privacy Policy

Last updated: August 2026

GZW Data API is a free, fan-made Gray Zone Warfare data project. This policy explains what information may be processed when you use the website or API.

Information we collect

GZW Data does not ask for accounts, names, email addresses, payment details, or other personal information. The website does not use advertising trackers, analytics software, or tracking cookies.

The API uses the requesting IP address temporarily for rate limiting. This helps enforce the limit of 100 requests per minute per IP address. We do not use this information to build user profiles.

Hosting and server logs

The site and API are hosted on Vercel. Vercel may process standard technical information, such as IP addresses, request timestamps, user-agent data, and request paths, in its infrastructure and security logs. These logs are controlled by the hosting provider and may be retained according to Vercel's policies. See Vercel's Privacy Policy for details.

Local storage and cookies

GZW Data does not intentionally store personal information in browser local storage and does not set tracking cookies. Your browser or the hosting infrastructure may still handle technically necessary data as part of delivering a web page or API response.

Data source and external links

The game data is sourced from the GZW Fandom Wiki. Links to external websites are governed by those websites' own privacy policies. GZW Data is not responsible for the privacy practices of third parties.

Changes to this policy

This policy may be updated when the site, API, hosting provider, or data practices change. The latest version will always be published on this page.

Contact

Questions or privacy concerns can be raised through the GZW Data GitHub repository.
